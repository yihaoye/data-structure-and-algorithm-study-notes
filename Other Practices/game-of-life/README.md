# 康威生命游戏
康威生命游戏是一个图灵完备的 zero-player cellular automation。除了二维版本外也有[三维版本](https://tkob-vh.github.io/posts/3d_conway_game/)，这里主要讨论二维版本。  
  
## 普通实现
最朴素的是使用二维数组来表示生命游戏的状态，使用循环来更新每一代的状态。但是缺点是空间复杂度和时间复杂度都比较高，尤其是当生命游戏的状态非常大时。因此，可以通过使用稀疏矩阵来表示生命游戏的状态，或者使用哈希表来存储活细胞的位置，从而减少空间复杂度和时间复杂度：
* [Go 实现](./main.go)
* [Java 实现](./Solution.java)
  
## 其他实现
使用 Bitboard 位级操作来表示生命游戏的状态，在某些场景下更适用（比如网格密度高、有边界固定大小的，但是在无边界或稀疏场景下哈希表仍然更优），时间复杂度仍为 O(N)。用二进制位表示每一行，或整个网格打包进若干个 64-bit 整数。  
  
## HashLife
Ref: https://nolebase.ayaka.io/zh-CN/%E7%AC%94%E8%AE%B0/%F0%9F%9B%A0%EF%B8%8F%20%E5%BC%80%E5%8F%91/%F0%9F%A7%AE%20%E7%AE%97%E6%B3%95/HashLife/HashLife.html  
  
一种压缩空间和时间的算法  
完全不同的范式 — 用四叉树（quadtree）+ 记忆化（memoization）来表示图案，对于大量重复、稀疏或规则结构的图案，可以指数级跳过大量演化步骤（比如直接算出 2^k 步之后的状态），特别适合模拟超大规模或超长时间的演化（如著名的 Gosper Glider Gun 或复杂图灵机模拟）。
